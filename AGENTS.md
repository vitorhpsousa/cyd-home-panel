# Notes for AI coding assistants

Read [docs/build-with-ai.md](docs/build-with-ai.md) before changing anything. It has the project map, how to add an
entity, the font and layout rules, and how to take screenshots to check your work.

The short version:

- PlatformIO, environment `cyd35`. Run `pio run` to build and `pio run -t upload` to flash.
- User settings live only in `src/panel_settings.h`, which is git-ignored. Its template is
  `src/panel_settings.example.h`. Never hard-code entity IDs, IPs, tokens or Wi-Fi details in source files, and never
  print them.
- The panel may only switch the Controls-page switches (`S_TILE1..S_TILE8`), and only while the page is unlocked.
  Keep the guard in `haSet()` and the lock in the Controls page. The Log page may only run its two shower scripts,
  pick a listed option on its one input_select and write logbook lines (`haShower`, `haFlow`, `haLog`), also only
  while unlocked.
- `src/fonts_aa.*` are generated by `tools/gen_fonts.py`, so don't edit them by hand.
